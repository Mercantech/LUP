# Havnekaptajnen og Aspire

[Aspire-kapitlet](https://lup.dk/notion/1a1ec2df-28e9-44d2-9c5c-df770c002380) bruger fire havnescener. Illustrationerne og de transparente emojis er genereret med ImageGen ud fra [LUPs portræt af havnekaptajnen](../../web/wwwroot/images/characters/whale/portrait.webp). Hvert motiv har en dansk billedplade til undervisning og en særskilt tegning til emoji-vælgeren. Begge udgaver bruger det [officielle Aspire-symbol](https://aspire.dev/community/brand/logos/).
