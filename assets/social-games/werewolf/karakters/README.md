# Werewolf · Karakters

Arkivet samler original AI-kunst skabt til LUP med én illustration pr. rolletype i *Karakters*. Navnene nedenfor er danske arbejdsnavne. [Åbn den samlede kortoversigt](kortoversigt.webp).

## De 16 roller i Karakters

Søstrene deler ét motiv på deres to kort, og brødrene deler ét motiv på deres tre. Æskens ekstra eksemplarer af den almindelige varulv og landsbyboeren kan bruge LUPs eksisterende illustrationer. [Se æskens indhold i regelhæftet, side 3](https://image.intertoys.nl/wcsstore/IntertoysCAS/images/catalog/manuals/1995320-0a030ce7.pdf#page=3).
